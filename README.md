## 📌 Project Overview

This project demonstrates a console-based airline reservation system developed using Java. The system allows users to manage flight bookings, view available flights, generate booking records, and cancel reservations using Object-Oriented Programming principles.

# ✈️ Flight Booking System

A console-based Flight Booking System developed using Java and Object-Oriented Programming (OOP) concepts. This application allows users to view available flights, book tickets, view booking details, and cancel reservations through a simple menu-driven interface.

---

## 🚀 Features

- View Available Flights
- Book Flight Tickets
- Generate Booking ID
- View Booking Details
- Cancel Bookings
- Menu-Driven Console Interface
- Object-Oriented Design

---

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- VS Code
